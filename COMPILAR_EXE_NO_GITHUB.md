# Gerar o EXE sem configurar o PC

Este pacote já contém `.github/workflows/build-windows.yml`.

1. Envie o conteúdo para um repositório privado no GitHub.
2. Abra **Actions > Build Windows EXE > Run workflow**.
3. Ao terminar, baixe o artifact **HMDS_Character_Translation_Studio_v0.10.0_Windows**.

O artifact contém `HMDS_Character_Translation_Studio_v0.10.0.exe`.

O usuário final não precisa instalar Python, Pillow, Tk ou Nuitka. Tudo necessário é incorporado ao executável onefile.
